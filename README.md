# AsiaSayesh

Corporate website for [AsiaSayesh](https://asiasayesh.com) — industrial abrasive products and solutions.

## Stack

- Next.js (static export)
- React
- Tailwind CSS
- pnpm

## Scripts

```bash
pnpm install
pnpm dev      # local development
pnpm build    # static export → out/
pnpm start    # serve out/
```

## Deploy

GitHub Actions builds and publishes `out/` to GitHub Pages. Custom domain: `asiasayesh.com`.
