# AsiaSayesh

Corporate site for [AsiaSayesh](https://asiasayesh.com).

## Stack

- Next.js (static export)
- React
- Tailwind CSS
- pnpm

## Scripts

```bash
pnpm install
pnpm dev      # local server
pnpm build    # static export to out/
pnpm start    # serve out/
```

## Deploy

Push to `master` runs GitHub Actions: build `out/`, publish to GitHub Pages at `asiasayesh.com`.
